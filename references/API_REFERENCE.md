# 元萝卜下棋机器人 API 参考文档

## 连接信息

- **IP 地址**: `192.168.199.10`
- **SSH 用户**: `root`
- **HTTP API 端口**: `60010`

---

## 一、HTTP API 接口

### 1.1 查看棋盘状态

- **URL**: `GET http://192.168.199.10:60010/skill-look-board`
- **说明**: 在执行任何操作前必须先调用此接口

### 1.2 取落子控制

- **URL**: `GET http://192.168.199.10:60010/skill-move-tcp`

| 查询参数 | 类型 | 说明 |
|----------|------|------|
| x | number | 横坐标 |
| y | number | 纵坐标 |
| action | integer | 0=移动、1=取子、2=落子 |

示例：
```
GET http://192.168.199.10:60010/skill-move-tcp?x=6&y=6&action=2
```

### 1.3 复位机械臂

- **URL**: `GET http://192.168.199.10:60010/skill-move-home`
- **说明**: 将机械臂归位到初始位置

### 1.4 自由取子

- **URL**: `GET http://192.168.199.10:60010/skill-catch-box`
- **说明**: 使用 CV 能力从棋盒中准确取子

### 1.5 清理棋盘

- **URL**: `GET http://192.168.199.10:60010/skill-clean-board`
- **说明**: 把棋盘上的子收回棋盒

### 1.6 语音播报

- **URL**: `GET http://192.168.199.10:60010/skill-tts-chinese`

| 查询参数 | 类型 | 说明 |
|----------|------|------|
| content | string | 要播报的中文内容 |

示例：
```
GET http://192.168.199.10:60010/skill-tts-chinese?content=你好
```

## 二、SSH 指令

所有 SSH 指令通过 `ssh root@192.168.199.10` 执行。

### 2.1 服务管理

| 操作 | 命令 |
|------|------|
| 恢复下棋 | `/etc/init.d/bi-app-sensechess restart` |
| 停止下棋 | `kkill proce sense` |
| 停止监控 | `kkill proce monitor` |

### 2.2 机械臂控制 (robotMcu)

```
robotMcu -- 0x11 0x12 x y 255 n 0 0
```

| 参数 | 类型 | 说明 |
|------|------|------|
| x | number | 横坐标 |
| y | number | 纵坐标 |
| n | integer | 0=移动、1=取子、2=落子 |
| 其他 | - | 固定值（0x11 0x12 ... 255 ... 0 0） |

**返回值**：`0` 表示成功，其它表示失败。

### 2.3 表情控制

```
media_service start_play_animation <number>
```

| 编号 | 表情 |
|------|------|
| 002 | 快乐 |
| 003 | 哭 |
| 004 | 默认 |
| 008 | 兴趣 |
| 011 | 摇头轻快 |
| 012 | 摇头否认 |
| 013 | 消失 |
| 014 | 出现 |

**前置条件**: 必须先执行 `kkill proce sense` 停止下棋。

## 四、错误处理

### 取子失败重试策略

1. 在棋盒随机位置取子
2. 若失败，在当前位置随机偏移 0.5 步长重试
3. 至多重复 3 次
